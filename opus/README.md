# BLOODMOON for Opus 2

BLOODMOON as a plugin for **[Opus 2](https://github.com/LizardMan245/opus)**, LizardMan's plugin manager for the
original OP-1 (firmware 246). It is the same dark organ and haunted bell as v1.3, with the same moon-and-cathedral
screen, rebuilt on Opus's own plugin kit so it loads as a native `.opmod` file. You don't need the Hundekraft Workshop
or Opus's op1r bridge for it.

> **Status: built and checked on a computer only.** Nobody has tried it on an OP-1 yet. Opus 2 itself is a beta.
> Please report what you see and hear.

## What you need

- An original OP-1 (not the Field) with **Opus 2** installed: core **2.6 or newer** (beta 3 has core 2.13). You make
  the Opus update from your own firmware with the patcher at https://opus-op1.pages.dev/patcher/.
- `bloodmoon.opmod`: in [the download zip](../download/bloodmoon-1.5.zip) (`opus/bloodmoon.opmod`), or on its own in
  [`download/opus/`](../download/opus/).

## Install

1. **Developer mode** (only for the first tries): hold **synth + drum + tape + mixer** for Opus's menu, then **T1**
   (system), and switch **developer mode** on. While it is on, Opus shows you what the plugin really does instead of
   leaving it out after a crash.
2. **Disk mode:** **shift + COM**, then **T3**, and connect the OP-1 to your computer.
3. Copy `bloodmoon.opmod` into the disk's **mods** folder. Eject the disk, then switch the OP-1 off and on.
4. Open Opus's menu again and press **T2** for the mods list. Turn **blue** to **bloodmoon**: the row should say
   **loaded**. If it shows a reason instead, please send it to us.
5. On a synth slot, press **shift + T1** and choose **bloodmoon** from the engine list. Start with the volume low.

**If something goes wrong:** hold **Stop** while you switch the OP-1 on. It starts with no plugins at all, so you can
delete `bloodmoon.opmod` from the mods folder in disk mode. Opus never touches te-boot, so you can always reinstall
(hold **COM** while you switch on).

## The knobs and the screen

These are the same as v1.3. See the main [README](../README.md) for what each knob does and how the screen follows it.
BLOODMOON takes no keys or shifted encoders. The OS's encoders turn its four knobs on T1, and T2 is the OS's
envelope, as before.

## What is different from the op1r version

- **Your sounds still load.** The engine claims op1r's sound type `bloodmoon`, so the v1.2 and v1.3 presets and
  sounds you saved with the op1r build load as this engine.
- **Don't load both.** If you also put `bloodmoon.op1p` in front of Opus's bridge, the two claim the same type, and
  Opus refuses the one that loads later.
- **Velocity is applied once.** Under Opus the OS scales each voice by velocity. The op1r build also scaled by it
  inside the engine, so soft notes come out a little louder here. Notes played at full velocity match v1.3 to within
  2 of 32,767.
- **LFO.** The knobs reach the engine with the OS's LFO already in them, so the T4 LFO can now move BLOOD, ECLIPSE,
  HAUNTING and MOONRISE.
- **CPU.** BLOODMOON hasn't been measured on an OP-1 yet, so Opus holds it to a tenth of the audio block until a
  `cpu.txt` is added. Once it has been played on a device (six-voice chords, every knob up, developer mode on), read
  "audio: worst N" from its details (**orange** push on its row) and put `cycles N` in
  `noladrift.bloodmoon/cpu.txt`.

## How it is built

| File | What |
|---|---|
| `noladrift.bloodmoon/manifest.txt` | The plugin's id (`noladrift.bloodmoon`), version and the core it needs |
| `noladrift.bloodmoon/bloodmoon.c` | The engine: v1.3's sound code on Opus's `struct opus_engine`, plus `opl_init` |
| `noladrift.bloodmoon/moon.c` | The T1 screen: v1.3's moon, bells, rose window, stars and digits, using the kit's named firmware calls |
| `noladrift.bloodmoon/bloodmoon.svg` | The screen art (unchanged from v1.3) |
| `noladrift.bloodmoon/bm_sine.h`, `bm_art.h` | Generated by `make_headers.py`: the sine table, and the SVG as a C string |
| `tests/compare.c`, `tests/run.sh` | Computer test: the port against v1.3, sound and screen |

The `.opmod` in `download/` was built once on GitHub with the kit's own compiler script and the Opus kit at commit
`d9b0d2e`. You only need what follows if you change the source.

To build it yourself, follow the kit's
[getting started](https://github.com/LizardMan245/opus/blob/main/plugin-kit/docs/getting-started.md) for the
compiler, then:

```
python path/to/opus/plugin-kit/plugin_tool.py build opus/noladrift.bloodmoon --out bloodmoon.opmod
```
